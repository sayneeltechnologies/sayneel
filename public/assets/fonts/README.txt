Place self-hosted web font files (.woff2) here.

The site currently loads Inter from Google Fonts. To remove that third-party
request, download Inter, drop the .woff2 files in this folder, add @font-face
rules to assets/css/styles.css, and delete the Google Fonts <link> tags from
the <head> of each .html file.

Full instructions: README.md, section 8.
